## 3. 直接 import Database 的违规扫描

`grep -r "import {.*Database.*} from.*data/Database" electron/services/` 应输出**空**。

如果仍有违规，按下述优先级迁移：
- P0: PublishService / TaskScheduler / AccountService / CommentService
- P1: ContentService / DraftService / StatsService
- P2: 其余 7 个
